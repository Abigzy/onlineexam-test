## 0. 使用说明

### 0.1 编号规则

`API-<模块>-<两位序号>`：模块缩写见下表；编号在增删用例时**不回收**，避免脚本引用错位。

| 缩写 | 模块 | 缩写 | 模块 |
|---|---|---|---|
| GEN | 通用契约 | ATT | 作答 |
| AUTH | 认证 | GRAD | 判分与成绩 |
| USER | 用户管理 | AN | 学情分析 |
| AI | AI 适配层 | REC | 个性化推荐 |
| KP | 知识点 | PRO | 作弊检测 |
| QUES | 题库 | CLS | 班级管理 |
| PAPER | 试卷与组卷 | SYS | 管理端 |
| EXAM | 考试配置 | — | — |

### 0.2 类型与层级

| 类型 | 含义 | 层级 | 正/反向 |
|---|---|---|---|
| 功能 | 合法输入下的业务正确性 | L1 | 正向 |
| 场景 | 跨接口串联 | L2 | 正向 |
| 一致性 | 数据重算、计数核对、软删可追溯 | L3 | 正向 |
| 幂等 | 重复动作结果不变 | L3 | 正向 |
| 可复现 | 同 seed / 同日同结果 | L3 | 正向 |
| 异常 | 业务规则拒绝、非法输入 | L1 | 反向 |
| 边界 | 阈值上下点 | L1 | 反向 |
| 权限 | 角色 / 数据范围 | L4 | 反向 |
| 安全 | 字段白名单、答案防泄漏 | L4 | 反向 |

> 说明：跨接口串联的"场景"不单列为一种类型（一条用例只能有一个类型），而是体现为"测试步骤含 ≥2 个接口"，其类型按主要断言归入功能 / 一致性 / 安全。第 1 节统计的"正向"已包含这类用例。

### 0.3 断言约定（所有用例默认适用）

1. **双断言**：HTTP 状态 + `code` 必须同时匹配；成功统一 `code == 0`。
2. **禁 500**：任何用例出现 500 一律判失败；参数类必须 400/404。
3. 预期里的 `S/C` 表示 `HTTP 状态 / 业务码`，如 `S400/C12030`。
4. 未特别说明时，请求均带对应角色 `Authorization: Bearer <access>`。
5. 时间类用例通过"造数时设相对时间"或"改 `deadline_at`"实现，**不 sleep**。
